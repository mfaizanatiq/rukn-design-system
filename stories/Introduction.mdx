# Rukn Design System

AI-ready, RTL-first primitives for Arabic, Urdu, and multilingual apps.

Use the **Theme** and **Locale** toolbar controls to preview dark/light and `en` / `ar` / `ur`.

## Bootstrap

```html
<link rel="stylesheet" href="styles/design-system-variables.css">

```
