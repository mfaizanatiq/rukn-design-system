# Rukn Design System

Storybook mirrors the **same CSS primitives** as [components.html](/components.html) on the live site.

## Use these first (Gallery)

| Story | Site equivalent |
|-------|-----------------|
| Gallery/Button | `btn-primary`, `btn-secondary`, … |
| Gallery/Input | `ds-input`, `ds-textarea`, `ds-select` |
| Gallery/Card | `ds-card`, `ds-glass` |
| Gallery/Badge | `ds-badge ds-badge-*` |
| Gallery/Alert | `ds-alert ds-alert-*` |

## Web Components

`<rukn-button>`, `<rukn-card>`, etc. are thin wrappers around those classes. Prefer the Gallery stories for visual QA against the website.

## Toolbar

- **Theme** — dark (default) / light
- **Locale** — en / ar / ur
