Designers pushing pixels and developers hand-rolling CSS was the last era. The next one is you describing the product — and AI composing interfaces from a design system it can actually read. Rukn is structured for that: semantic tokens, documented components, zero hidden magic.

Step 1

Describe

Tell your agent what you're building — in English, Arabic, or Urdu. A checkout flow, admin panel, landing page. No Figma file required.

Step 2

Compose

The agent reads Rukn's tokens, class names, and Web Components — then assembles production markup. btn-primary, ds-card, rukn-navbar. Predictable. Copy-pasteable. Correct.

Step 3

Ship

You review, refine, and deploy. Build on top of the primitives — extend tokens, wrap components, own the stack. MIT licensed. Zero dependencies.
